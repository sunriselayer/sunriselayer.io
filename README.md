# sunriselayer.io

The Sunrise Edge website. The landing page introduces the protocol, while `/migration/` explains the move from Cosmos Sunrise.

## Stack

- Astro
- Svelte
- Tailwind CSS
- shadcn-svelte (Luma)
- Lucide icons

## Development

```sh
pnpm install
pnpm dev
```

Run the local validation gate with:

```sh
pnpm check
pnpm format:check
pnpm build
```
