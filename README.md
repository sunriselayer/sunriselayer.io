# sunriselayer.io

The one-page website for Sunrise and the in-development Sunrise Edge protocol.

## Stack

- Astro
- Svelte
- Tailwind CSS
- shadcn-svelte (Luma)
- Lucide icons

## Development

```sh
pnpm install
pnpm dev
```

Run the local validation gate with:

```sh
pnpm check
pnpm format:check
pnpm build
```
